# RGK Santafesino (versión de prueba)

Prototipo para administrar torneos de karting: inscripción de competidores, categorías, carga de tiempos y torneos pasados.

- Panel del organizador: `index.html`
- Formulario del competidor: `inscripcion.html` (redirige a `index.html#inscripcion`)

Es una versión de demostración: arranca con datos de ejemplo y guarda los cambios en el navegador de cada dispositivo.
